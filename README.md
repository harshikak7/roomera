# Roomera – Smart Roommate Finder (demo)

## Run it live
1. Install Python 3.9+
2. In this folder: `pip install -r requirements.txt`
3. `python app.py`
4. Open http://localhost:5000

Flask serves the React frontend (index.html) and the matching API
(/api/recommendations). Internet is needed for the React CDN scripts.

No Python? Double-click index.html – it falls back to in-browser scoring.
